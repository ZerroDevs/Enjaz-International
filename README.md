# Enjaz International Oilfield Services Website

A modern, responsive, and mobile-first website created for **Enjaz International Oilfield Services (شركة انجاز الدولية للخدمات النفطية)**. 

The website provides comprehensive details regarding the company's profile, objectives, core services in the oil & gas industry, and contact information.

## Features
- **Mobile-first Design**: Optimized for a seamless experience on smartphones and tablets.
- **Scroll Reveal Animations**: Smooth entry animations for content.
- **Interactive UI**: Custom sliders and responsive navigation.
